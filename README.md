# Met-Lit-Contrast

This repository contains the data collected and analyzed as well as all feature scores presented in the paper [_Floating_ or _Suggesting Ideas_? A Large-Scale Contrastive Analysis
of Metaphorical and Literal Verb–Object Constructions](https://arxiv.org/abs/2604.08275), published at CMCL@LREC 2026.
